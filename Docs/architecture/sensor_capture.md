# Sensor capture

Status: normative.

The current immutable image-plane illuminance is the output of the shared optical-cover and lens evaluation. Sensor capture never reevaluates or substitutes either material response.

The lens evaluator ends at immutable linear ACEScg image-plane illuminance on the virtual sensor plane. Application integrates it with the explicit shutter duration and optical ND into lux-seconds. `screen-sensor` owns the next physical boundary: conversion of that explicitly time-integrated absolute optical exposure into one mosaiced RAW sensor raster. It never projects geometry, evaluates a panel, decodes media, chooses color interpretation, demosaics, applies a creative look or encodes an image.

The current shutter explicitly authors either global readout or rolling readout. Exposure duration and rolling readout duration are positive exact rational seconds; motion-sample count is authored in `[1, 64]`. A frame-capture request owns frame rate, frame index, optical ND and noise seed together; Application derives both exact project time and sensor noise identity from that single index, so an adapter cannot pair the optical time with another frame's noise pattern. Application treats the derived project time as the complete-frame temporal center. Global readout gives every row that center. Rolling readout distributes row centers exactly across the readout interval in authored top-to-bottom or bottom-to-top order. Each row exposure is divided only by its authored uniform motion-sampling boundaries. One midpoint resolves source, camera and screen animation for each interval and carries that interval's exact duration as its integration weight. Panel emission is separable from that spatial optical evaluation: residual flicker and optional duty-cycle banding are integrated analytically over the complete interval, then applied only to emissive panel radiance. Cover reflection is not modulated. The accumulated result is ACEScg illuminance-seconds. Floating-point seconds appear only when exact interval durations cross the optical accumulation boundary.

Analytic duty-cycle integration supports at most 4096 exact banding transitions in one motion interval. Exceeding that declared capacity is an explicit error before the affected spatial optical evaluation can publish. Increasing motion samples refines authored scene motion only; it is never required to resolve panel flicker or banding and cannot multiply optics merely because the panel frequency changes.

The current sensor profile explicitly authors one native photosite raster, a Bayer pattern, a finite invertible and well-conditioned ACEScg-to-sensor tristimulus approximation, per-channel saturation illuminance exposure in lux-seconds, full-well capacity in electrons, dark current in electrons per second, read-noise RMS in electrons, analog gain and ADC bit depth. The camera intrinsics remain the single owner of physical gate width and height; together with the sensor-owned native raster they determine photosite pitch without duplicating physical dimensions. Every capture derives its optical raster from this native sensor raster, and `screen-sensor` rejects a differently sized integrated exposure rather than resampling or accepting another resolution authority. Application also requires the native raster aspect to match the camera gate at every evaluated time. Negative native sensor responses produced by the tristimulus approximation are zero at the photosite because negative photoelectrons have no physical meaning. This clamp belongs to the sensor boundary and does not alter the upstream linear optical result.

Each photosite records exactly one channel selected by the authored Bayer pattern, whose first pair is anchored at the top-left of the final sensor raster after canonical viewport-to-row conversion. Ideal signal charge is scaled by full-well capacity. Shot noise and dark-current noise use a deterministic Poisson approximation. Their collected charge saturates at the physical full-well boundary; zero-mean Gaussian read noise is then added downstream, followed by analog gain, ADC clipping and explicit 8–16-bit quantization. Distinct per-photosite masks record full-well saturation and ADC saturation, so analog gain cannot change whether the charge well itself overflowed. Randomness is counter-based from the authored shot seed, exact frame index and photosite index, so evaluation order and Rayon scheduling cannot change a RAW result. The authoritative result is the mosaiced integer RAW plus both clipping masks and the complete immutable sensor-profile identity that produced them. A dimension-, CFA- and ADC-compatible but differently calibrated profile is not the same RAW identity and cannot develop it. Demosaic and camera color processing are later output boundaries and cannot be folded into sensor capture.

Independent photosites may execute in parallel, but one- and multi-worker executions must return
identical integer codes and clipping masks. Global-shutter integration may parallelize pixels and
rolling-shutter integration may parallelize rows; the temporal samples within every pixel or row
remain in authored order. Parallelism is therefore an execution detail inside this single sensor
contract, never a quality mode or alternate result route.

`SensorRegion` is an exact restriction of that complete raster, never a second sensor or a scaled preview. It carries its global origin and validates against the authored native raster. CFA selection and the counter-based noise index always use global photosite coordinates. Application may partition a native capture into independent tiles, but every tile evaluates the same full-gate ray coordinates and the same complete device signal. Camera development expands a requested region by the complete three-photosite support needed by the current edge-directed demosaic and crops only after reconstruction. Tests require regional RAW/noise and developed output to equal the corresponding crop of complete-frame evaluation, including regions whose origin changes Bayer phase.

The desktop may display completed tiles through a throttled, downscaled staging image while native capture is running. Its reduction averages every completed native sample assigned to each staging cell; it must not select one representative sample, read pending pixels as black, or introduce a second aliasing result. Unsampled cells use an explicit presentation background. Staging is presentation-only and is never the capture result: the complete native buffer remains private to the worker and is published atomically only after all exact global-coordinate tiles finish. After completion, the presentation adapter derives successive exact 2× area-filtered levels and selects a level appropriate to viewer magnification; it must not ask the UI toolkit to minify the complete native texture directly. The native output-transformed level-zero publication buffer remains the only level used by `1:1 Sensor` and output PNG export; the PNG encoder receives that same immutable byte buffer without rerendering or display resampling. Cancellation discards staging and retains the last complete published capture. A center ROI and a complete frame are explicit `SensorRegion` choices using the same evaluator.

The technical workstation measures Native execution at existing semantic boundaries only: output-processor preparation, combined physical capture plus camera development, output-transform plus level-zero assembly, and presentation-pyramid construction. These elapsed durations are diagnostic workstation data and never enter project state or select an evaluator. The combined physical measurement is intentionally not presented as separate optics, sensor and demosaic timings until those owners expose measured boundaries without duplicating their route.

Draft, Medium and High in the camera-result view are one explicitly non-authoritative camera-preview route. They evaluate the same full gate and linear lens result, integrate the same shutter duration and optical ND, place middle gray from the same EI and develop exposure, then use the same camera output transform. They intentionally omit photosite sampling, CFA mosaic, sensor clipping/noise, demosaic and sensor color-matrix response. Consequently they may guide framing, focus and exposure but cannot validate aliasing, moire, noise, clipping or color separation. Native region and native complete frame remain the only sensor results.

`screen-camera` is the only downstream owner of camera development. It verifies complete sensor-profile equality against RAW identity and reconstructs native sensor exposure through one deterministic edge-directed Bayer algorithm. Green at red/blue sites uses a gradient-selected color-corrected directional estimate; missing red/blue values interpolate the corresponding color difference over the one CFA-valid axis or diagonals. Image boundaries use the same normalized available-support rule, not another algorithm. This suppresses false chroma at luminance edges while preserving CFA-authored chromatic structure. Camera development then applies one explicit three-channel white-balance gain in native sensor RGB, the inverse of the authored sensor matrix and explicit EI middle-gray placement plus develop push/pull to publish immutable scene-linear ACEScg. The ideal interactive preview uses that same sensor-basis white-balance operation before omitting the RAW-only stages. EI changes development placement and exposure guidance; it never changes collected photons, full-well capacity or repairs pre-sensor clipping. The transform preserves finite negative and above-one values produced by the sensor matrix. Demosaic, white balance and development never alter the authoritative RAW raster.

This is a physically motivated tristimulus/electron approximation rather than a spectral sensor model. The current contract does not claim wavelength-resolved quantum efficiency, pixel crosstalk, microlens angular response, fixed-pattern noise, defective pixels, panel scanout or sample-and-hold refresh addressing. Current LCD/OLED-style authoring defaults to readable clean emission with only low residual temporal modulation. Visible bands are an explicit optional, duty-normalized analytic approximation derived from panel period, duty, phase, shutter and row time; they are disabled by default and are not a second image post effect. CRT requires a later technology-specific emission model rather than reuse of this contract.
