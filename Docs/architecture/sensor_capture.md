# Sensor capture

Status: normative.

The lens evaluator ends at immutable linear relative ACEScg irradiance on the virtual sensor plane. `screen-sensor` owns the next physical boundary: conversion of an explicitly time-integrated optical exposure into one mosaiced RAW sensor raster. It never projects geometry, evaluates a panel, decodes media, chooses color interpretation, demosaics, applies a creative look or encodes an image.

The current shutter explicitly authors either global readout or rolling readout. Exposure duration and rolling readout duration are positive exact rational seconds; temporal sample count is authored in `[1, 64]`. Application treats requested project time as the complete-frame temporal center. Global readout gives every row that center. Rolling readout distributes row centers exactly across the readout interval in authored top-to-bottom or bottom-to-top order. Each row exposure is first divided by its authored uniform motion-sampling boundaries and then additionally partitioned at every exact panel PWM transition. One midpoint sample represents each resulting constant-PWM interval and carries that interval's exact duration as its integration weight. Therefore even one authored motion sample integrates binary PWM duty cycle without temporal aliasing, while higher authored counts refine source, camera and screen motion through the same route. Every temporal sample resolves camera and screen animation, panel PWM phase and the device-signal raster at that same exact time. The source provider remains responsible for the already-authored media sample policy and supplies a prepared immutable raster that may be cached by resolved source sample; the shutter never freezes, holds or invents a source frame. The accumulated result is ACEScg irradiance-seconds. Floating-point seconds appear only when exact interval durations cross the optical accumulation boundary.

The current sensor profile explicitly authors a Bayer pattern, a finite invertible and well-conditioned ACEScg-to-sensor tristimulus approximation, per-channel saturation exposure, full-well capacity in electrons, dark current in electrons per second, read-noise RMS in electrons, analog gain and ADC bit depth. Negative native sensor responses produced by the tristimulus approximation are zero at the photosite because negative photoelectrons have no physical meaning. Above-range charge clips only at full-well/ADC capture. This clamp belongs to the sensor boundary and does not alter the upstream linear optical result.

Each photosite records exactly one channel selected by the authored Bayer pattern, whose first pair is anchored at the top-left of the final sensor raster after canonical viewport-to-row conversion. Ideal signal charge is scaled by full-well capacity. Shot noise and dark-current noise use a deterministic Poisson approximation; read noise uses a deterministic zero-mean Gaussian approximation. Randomness is counter-based from the authored shot seed, exact frame index and photosite index, so evaluation order and Rayon scheduling cannot change a RAW result. Analog gain precedes ADC clipping and explicit 8–16-bit quantization. The authoritative result is the mosaiced integer RAW plus a per-photosite clipping mask. Demosaic and camera color processing are later output boundaries and cannot be folded into sensor capture.

This is a physically motivated tristimulus/electron approximation rather than a spectral sensor model. The current contract does not claim wavelength-resolved quantum efficiency, pixel crosstalk, microlens angular response, fixed-pattern noise, defective pixels, panel scanout or sample-and-hold refresh addressing. Binary backlight PWM, rolling readout and their phase interaction are evaluated physically in time rather than synthesized as post effects.
